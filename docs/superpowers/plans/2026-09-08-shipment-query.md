# 发货查询模块实施计划

**目标：** 新增只读“发货查询”页面，可按订单号、客户单位和项目筛选发货单，并查看对应产品基础信息。

**实现范围：**

- 使用现有销售出库单、销售发货扩展信息、出库明细和物料基础资料，不新增数据库表。
- 客户单位、项目使用可搜索下拉栏；订单号同时支持匹配销售订单号和发货单号。
- 发货清单显示客户、物流、数量及退回状态，选中清单后联动显示产品编码、名称、规格、项目、类别、批次和仓库等信息。
- 将页面接入主菜单、手动刷新和库存数据刷新链路。
- 按用户后续要求，项目测试目标和测试源文件已移除，默认关闭 `BUILD_TESTING`；本次不执行构建。
