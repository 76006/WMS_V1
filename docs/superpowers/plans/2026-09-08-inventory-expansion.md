# 库存功能扩展实施计划

**目标：** 一次性补齐旧库存 Excel 导入、普通出入库多物料、库存调拨和库存盘点四项功能，并保持库存台账、批次和单据事务一致。

## 任务 1：扩展库存服务

- [x] 增加普通多物料入库/出库的原子提交接口与重复提交保护。
- [x] 增加期初库存导入接口，可自动创建不存在的物料并生成期初入库单。
- [x] 增加盘点确认接口，记录账面数、实盘数和差异，并生成盘盈/盘亏流水。
- [x] 保留并复用现有单行调拨接口。

## 任务 2：实现旧库存 Excel 解析与导入页

- [x] 直接解析 `.xlsx` 工作簿，不依赖本机安装 Excel。
- [x] 适配四张原材料表及“成品”分段快照；跳过零库存，明确提示负数、斜杠和缺少编码的数据。
- [x] 提供文件选择、仓库/库位、预览、错误提示及正式导入。
- [x] 用文件摘要和目标库位防止同一份期初库存重复导入。

## 任务 3：改造普通出入库

- [x] 将普通入库和普通出库改为可增删多行物料的单据表格。
- [x] 入库支持手工批次和序列号；出库继续按现有库存批次和序列号选择。
- [x] 整单校验、整单提交、失败全部回滚。

## 任务 4：实现调拨与盘点页面

- [x] 调拨页支持来源物料、批次、序列号及目标仓库/库位。
- [x] 盘点页按仓库/库位加载库存快照，录入实盘数与差异原因后确认。
- [x] 序列号物料允许无差异确认；发生数量差异时给出明确限制提示，避免账物序列号不一致。

## 任务 5：集成与验证

- [x] 更新 CMake 和数据库/服务自动化测试。
- [x] 完整构建并运行测试，修复编译或回归问题。
- [x] 更新 README 功能说明与已知导入规则。
