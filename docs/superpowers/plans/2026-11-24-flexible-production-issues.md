# 联网生产领料同步步骤

依据同日设计，以单机提交 `c89e9b8` 为参照，将改动应用到联网分支。

1. 数据库和旧库导入。增加联网迁移 25，调整 PostgreSQL 批号唯一键，添加每单台数字段。识别单机 SQLite 的版本 22 与联网版本 22 的差异。测试旧批次外键、两类版本 22 及同名批次的导入。
2. 单据提交与修订。按成品和批次复用生产任务，在领料单记录台数。领料明细允许同库存分行，阶段校验按 BOM 成员和实领数执行，维持整单事务、SN 和重复提交保护。
3. 界面。区分本次台数和计划台数，保留手调实领量。阶段进度显示原计划、净已领和尚待领数量。退料、表单与 SN 追溯随来源单据读取信息。
4. 验证。运行临时 PostgreSQL 业务集成、旧库导入、阶段领料和打印字段回归，构建冰美肌和美鲸灵客户端及后台，更新联网版外发包。使用本地编译输出和隔离测试库验收。
