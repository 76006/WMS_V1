# 联网版按单领料

将单机版 main 提交 `c89e9b8` 的生产领料行为同步到冰美肌和美鲸灵联网客户端及后台。

## 业务规则

- 同一成品、同一生产批次可多次领料。每张领料单保存本次生产台数，任务原计划台数用于阶段进度和完工统计。不同成品可以使用相同的生产批次号。
- BOM 按本次台数预填领料量。操作员可调整实领数量，可将同一物料分行从同一或不同库存批次领出。已手工调整的数量在改变台数时予以保留。
- 阶段领料有两种处理方式。保留原上限会拒绝超过阶段计划的数量。用户选择允许超过阶段计划，按实际数量扣库。例如计划 10、已领 8、本次领 3，成功后累计 11、待领 0。阶段成员、库存余额、SN、权限与整单事务校验仍然适用。
- 退料、撤销、单据修改和表单重生成使用原领料明细，本次台数追溯到相应领料单。通过来源单据关联 SN，避免同批次号的不同成品串单。

## 联网适配和验收

复用现有 Qt 界面、RPC 及服务端库存事务。新库与存量 PostgreSQL 库均支持“成品＋批次”的唯一约束和可空的单据台数字段。历史无台数的单据沿用原计划数。兼容旧 SQLite 库导入，按实际表结构处理两条分支对迁移号 22 的不同用途。

使用隔离库验证后台入账、打印数据、同批号不同成品、同库存分行、阶段超计划、库存不足整单回滚以及重复请求。以联网客户端和服务端匹配的构建验收。
