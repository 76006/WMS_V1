# 左侧导航可读性修复设计

日期：2026-09-07

## 目标

解决主窗口左侧导航出现浅色背景配浅色文字、菜单内容难以辨认的问题，同时保持现有深蓝品牌侧栏和页面布局不变。

## 原因

`sidebar` 外框已设置深蓝背景，但其中的 `QScrollArea` 视口和导航容器仍使用默认浅色背景；导航按钮文字却按深色背景配置为浅灰色，形成低对比度显示。选中态和悬停态也因此不够稳定、清晰。

## 修改方案

- 为侧栏滚动区和导航内容容器设置明确对象名，并统一使用 `#172033` 深蓝背景。
- 普通菜单文字使用 `#E2E8F0`，字号调整为 14px、字重 500。
- 悬停状态使用 `#26344D` 背景和白色文字。
- 当前选中项继续使用 `#2563EB` 蓝色背景、白色半粗体文字。
- 禁用菜单使用 `#64748B`，与可操作菜单形成明显区别。
- 键盘焦点增加浅蓝边框，保证不用鼠标时也能识别当前焦点。
- 不修改侧栏宽度、菜单顺序、权限逻辑和任何业务页面。

## 验证

- 全量构建通过。
- 现有 5 项自动化测试全部通过，包含界面构造冒烟测试。
- 深蓝背景覆盖品牌区、菜单滚动区和底部空白区。
- 普通、悬停、选中、禁用和键盘焦点状态均能清晰区分。
- 菜单文字在 100% Windows 缩放下清晰可读，不出现裁切。
