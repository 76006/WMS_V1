# 冰美肌库存管理系统

面向小规模生产制造企业的 Windows 单机仓库管理系统。项目使用 Qt Widgets 开发，以物料、仓库和库位为基础，通过入库、出库、生产领退料、成品入库、调拨和盘点形成完整库存闭环。

设计重点：库存准确、操作简单、方便追溯，不包含金额、审批流、扫码和大型 ERP 功能。

## 技术方案

- Qt 6.5 或更高版本
- C++17
- CMake
- Qt Widgets
- Qt SQL
- QSQLITE
- Windows 64 位

程序使用本地 SQLite 数据库文件。首次启动时自动建立数据表、基础角色、物料分类和默认管理员。业务附件也将以 BLOB 形式保存在数据库文件中。

默认数据库位置由 `QStandardPaths::AppLocalDataLocation` 决定，通常位于当前 Windows 用户的应用数据目录。

## 已实现的库存原则

- 库存不允许直接人工修改。
- 库存变化必须由业务单据产生。
- 每次变化自动生成库存流水。
- 出库和调拨不能造成负库存。
- 单据编号在库存事务内生成。
- 支持按物料、仓库、库位和批次保存余额。
- SN 管理物料的业务数量必须和 SN 数量一致。
- 已生效业务通过反向记录处理，核心服务支持部分撤销。

## 首次登录

首次创建数据库时生成以下账号：

```text
用户名：admin
密码：Admin@123
```

正式使用前必须修改默认密码。密码使用 PBKDF2-SHA256 加盐保存。

## 本地构建

示例：

```powershell
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH=D:\Qt\6.5.3\mingw_64
cmake --build build
ctest --test-dir build --output-on-failure
```

项目当前仍缺少部分页面源码，完成首次构建修正前，上述命令可能失败。

## 数据安全

真实库存 Excel、运行中的 SQLite 数据库、WAL 文件和构建产物均被排除在版本库之外。后续应使用脱敏后的标准 Excel 模板进行导入功能开发。
