# 冰美肌库存管理系统

面向小规模生产制造企业的 Windows 单机仓库管理系统。项目使用 Qt Widgets 开发，以物料、仓库和库位为基础，通过入库、出库、生产领退料、成品入库、调拨和盘点形成库存闭环。

设计重点：库存准确、操作简单、方便追溯，不包含金额、审批流、扫码和大型 ERP 功能。

## 技术方案

- Qt 6.5 或更高版本
- C++17
- CMake
- Qt Widgets
- Qt SQL
- QSQLITE
- Windows 64 位

程序使用本地 SQLite 数据库文件。首次启动时自动建立数据表、基础角色、物料分类和默认管理员；后续启动自动执行增量迁移。业务附件预留为以 BLOB 形式保存在数据库文件中。

默认数据库位置由 `QStandardPaths::AppLocalDataLocation` 决定，通常位于当前 Windows 用户的应用数据目录。

## 当前状态

项目正在开发中。目前已经完成数据库结构与版本迁移、登录、主界面、物料管理、仓库库位管理、普通入库与出库、库存查询、库存流水、部分撤销，以及生产领料、关联原领料的部分退料和成品入库闭环。

生产业务支持一张领料单包含多条物料、普通物料与 SN 物料混合处理、整单原子提交、重复提交拦截、生产批次进度统计，以及生产单据撤销后的数量和状态回算。

Qt 主程序已完成全量构建，密码、SQLite 库存事务、生产业务集成测试和界面构造冒烟测试均已通过。详细进度见 [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md)。

## 已实现的库存原则

- 库存不允许直接人工修改。
- 库存变化必须由业务单据产生。
- 每次变化自动生成库存流水。
- 出库、生产领料和调拨不能造成负库存。
- 单据编号在库存事务内生成。
- 多明细生产单据整单成功或整单回滚。
- 提交令牌避免重复生成同一张生产单据。
- 支持按物料、仓库、库位和批次保存余额。
- SN 管理物料的业务数量必须为整数并与 SN 数量一致。
- 生产退料必须关联原领料明细，并受剩余可退数量约束。
- 已生效业务通过反向记录处理，核心服务支持部分撤销。
- 累计成品入库达到计划数量时自动完成生产批次，撤销后自动重算。

## 首次登录

首次创建数据库时生成以下账号：

```text
用户名：admin
密码：Admin@123
```

正式使用前必须修改默认密码。密码使用 PBKDF2-SHA256 加盐保存。

## 本地构建

示例：

```powershell
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH=C:\Qt\6.10.2\mingw_64
cmake --build build
ctest --test-dir build --output-on-failure
```

当前开发环境已使用 Qt 6.10.2 MinGW 64 位完成构建和全部测试。

## 数据安全

真实库存 Excel、运行中的 SQLite 数据库、WAL 文件和构建产物均被排除在版本库之外。后续应使用脱敏后的标准 Excel 模板进行导入功能开发。
