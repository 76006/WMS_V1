# 冰美肌库存管理系统

面向小规模生产制造企业的 Windows 单机仓库管理系统。项目使用 Qt Widgets 开发，以物料、仓库和库位为基础，通过入库、出库、生产领退料、成品入库、调拨和盘点形成库存闭环。

设计重点：库存准确、操作简单、方便追溯，不包含金额、审批流、扫码和大型 ERP 功能。

## 技术方案

- Qt 6.5 或更高版本
- C++17
- CMake
- Qt Widgets
- Qt SQL
- QSQLITE
- Windows 64 位

程序使用本地 SQLite 数据库文件。首次启动时自动建立数据表、基础角色、物料分类和默认管理员；后续启动自动执行增量迁移。业务附件预留为以 BLOB 形式保存在数据库文件中。

默认数据库位置由 `QStandardPaths::AppLocalDataLocation` 决定，通常位于当前 Windows 用户的应用数据目录。

## 已实现的库存原则

- 库存不允许直接人工修改。
- 库存变化必须由业务单据产生。
- 每次变化自动生成库存流水。
- 出库、生产领料和调拨不能造成负库存。
- 单据编号在库存事务内生成。
- 普通出入库和生产单据均支持多物料，整单成功或整单回滚。
- 提交令牌避免重复生成同一张普通、生产、导入或盘点单据。
- 支持按物料、仓库、库位和批次保存余额。
- SN 管理物料的业务数量必须为整数并与 SN 数量一致。
- 生产退料必须关联原领料明细，并受剩余可退数量约束。
- 已生效业务通过反向记录处理，核心服务支持部分撤销。
- 累计成品入库达到计划数量时自动完成生产批次，撤销后自动重算。
- 库存调拨在同一事务中完成来源扣减、目标增加、双向流水和 SN 位置更新，并支持普通物料与 SN 物料部分或全部撤销。
- 库存盘点保存账面数、实盘数和差异原因，确认时自动形成盘盈/盘亏流水。
- 批次查询汇总供应商、当前库存、库位数和实际使用的生产批次，并可下钻查看全部库存流水。
- SN 查询展示当前状态、位置、出库时间、生产批次、实际领用物料批次、关联附件和完整生命周期流水。
- 业务单据附件以 BLOB 保存到 SQLite，支持下载、软删除和恢复；图片、PDF、现代 Excel/Word 可在应用内预览，单文件上限 50 MB。
- 管理员可新增用户、调整角色和启停状态、重置密码；系统阻止停用当前账号和移除最后一个启用管理员。
- 当前用户可修改自己的密码，密码继续使用 PBKDF2-SHA256 加盐保存。
- 管理员可为角色配置物料、库存、生产、附件、用户、系统和日志权限。
- 仓库或库位仍有库存时禁止停用，防止形成不可用库存。
- 单据编号前缀与流水位数可配置，重复或非法规则会被拒绝。
- 新增物料编码按“物料类型 M/P/O + 项目代码 + 专业类别 1/2/9 + 三位流水号”自动生成；各编号前缀独立递增且保存后不可修改。
- 入库、出库、调拨、生产领退料、成品入库和盘点均支持按物料编码或名称检索并带出相应基础资料。
- 采购入库逐行记录采购数量、实际入库数量和其中赠送数量；赠送量不计入对账数量，采购差异在提交前提示。
- 采购入库部分撤销可指定其中撤销的赠送数量，保证赠送和对账净量同步回冲。
- 出入库统计支持年度按月汇总和月度物料进销存，内部调拨不重复计入公司级出入库总量。
- 月报 Excel 包含“月度汇总”和“出入库明细”两个工作表，保留采购、实收、赠送、对账、期初与期末库存口径。
- 物料档案保存单台用量、加工方式和正常/停用状态；有库存的物料禁止直接停用。
- 生产领料按生产台数自动计算每种物料的总用量，批次继续由用户选择。
- 生产领料单号使用 `SMLL + yyyyMMdd + 三位当日流水号`，例如 `SMLL20260908001`。
- 物料管理支持多选后批量修改物料类别、加工方式、单位、单台用量、最低库存和物料状态。
- 选择销售出库时显示客户公司、目的地、联系人、电话、销售订单、物流公司和运单号；客户公司与目的地必填，其他出库类型不显示也不校验这些字段。
- 销售信息与出库单一对一保存在 SQLite 中，近期出库列表显示客户和目的地，双击销售出库可查看完整资料。

## 物料档案 Excel 导入

“物料管理”的 Excel 导入兼容标准模板和现有 `物料档案.xlsx`：表头可按名称识别，“物料类别”既可填写分类编码，也可直接填写原材料、半成品、成品、辅料耗材等中文名称。

- 模板包含单台用量、现有库存、物料类别、加工方式和物料状态。
- 默认仓库可以单独填写；只有填写默认库位时才要求同时填写仓库。
- 完全重复的物料编码自动跳过，同一编码但资料不同会阻止导入并提示具体原因。
- 零库存仍会建立或更新物料档案；正库存可按默认仓库和库位生成期初库存记录。
- 已经发生库存业务的物料，其“现有库存”只用于核对，不会重复入账。
- 批次或 SN 管理物料导入正库存时，需要同时提供对应库存批次或完整 SN 清单。

## 旧库存 Excel 导入

“库存Excel导入”页面可直接解析 `冰美肌库存-0629.xlsx` 的现有结构，无需安装 Microsoft Excel。系统读取四张原材料/耗材表和“成品”表的最新库存区段，同物料同批次会合并后预览。

- 正库存可导入，并自动创建数据库中不存在的物料。
- 零库存、斜杠和空数量会跳过；负库存、缺少编码或名称的数据会明确报错且不入账。
- 导入生成“其他入库”类型的期初库存单和库存流水。
- 同一个文件导入到同一个库位时会被重复提交保护拦截。
- Excel 本身不包含可靠的单位和 SN 清单，新增物料单位默认使用“个”，不会自动启用 SN 管理；有批次号的新增物料会启用批次管理。

## 首次登录

首次创建数据库时生成以下账号：

```text
用户名：admin
密码：Admin@123（Debug 测试版本中 admin 可暂时留空密码）
```

正式使用前必须修改默认密码。密码使用 PBKDF2-SHA256 加盐保存。

## 本地构建

示例：

```powershell
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH=D:\Qt\6.5.3\mingw_64
cmake --build build
ctest --test-dir build --output-on-failure
```

当前开发环境已使用 Qt 6.5.3 MinGW 64 位完成构建和全部测试。

## Windows 发布

执行 `scripts/package-windows.ps1` 会自动匹配本机 Qt 6 MinGW 工具链，在 `dist` 目录生成便携运行目录、免安装 ZIP 和 `IceBeautyWms-Setup.exe`。加上 `-ZipOnly` 时只生成便携目录和 ZIP，不生成安装程序。脚本会检查 Windows 平台插件与 SQLite 驱动，并在不依赖 Qt 开发环境变量的情况下执行一次独立启动验证；也可通过 `-QtRoot` 显式指定 Qt 路径。安装程序默认安装到当前用户的 `%LOCALAPPDATA%\Programs\IceBeautyWms`，不会覆盖数据库目录。

项目约定：开发阶段不自动执行发布脚本；仅在 Debug 人工调试完成且用户明确要求后生成安装程序和 ZIP。

## 数据安全

真实库存 Excel、运行中的 SQLite 数据库、WAL 文件和构建产物均被排除在版本库之外。代码仓库只保存导入规则，不会上传真实库存数据。
